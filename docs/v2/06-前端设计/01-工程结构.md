# 06-01 前端工程结构

## 1. 基座选型

以 [satnaing/shadcn-admin](https://github.com/satnaing/shadcn-admin) 模板为起点（degit 克隆后裁剪）。其技术栈与本项目需求完全对口：

- React 19 + Vite + TypeScript
- **TanStack Router**（文件路由、类型安全）+ **TanStack Query**（数据获取）
- shadcn/ui + Tailwind CSS v4
- 内置：可折叠侧边栏布局、暗色/亮色主题、cmdk 全局搜索、面包屑

裁剪：删除模板的 tasks / profile / 样例 API mock；保留 layout / theme / sidebar / search 骨架。

## 4. 构建与开发

```jsonc
// web/package.json scripts
{
  "dev": "vite",                      // 开发时 /api 代理到 http://127.0.0.1:1999
  "build": "tsc -b && vite build --outDir ../server/web-dist --emptyOutDir"
}
```

```ts
// vite.config.ts
export default defineConfig({
  server: { proxy: { '/api': 'http://127.0.0.1:1999' } },
  // 允许反代域名访问 dev server（v1 的 allowedHosts: true 场景）
  server: { allowedHosts: true, ... },
})
```

生产模式由 Fastify 托管 `server/web-dist`（SPA fallback 到 index.html），同源无 CORS。

## 5. 认证守卫（__root.tsx）

```tsx
// 伪代码
const { data: session } = useSession()          // GET /api/v1/auth/session
if (session === undefined) return <SplashScreen />
if (!session.authenticated) return <Redirect to="/login" />
if (!session.password_initialized && !isSettingPassword) return <Redirect to="/login?setup=1" />
return <Outlet />
```

`/login` 路由在 `_auth` 布局之外（无侧边栏）。API 层任何 401 → 跳转 `/login`（见 06-03）。

## 6. 国际化策略

模板为英文。本项目**界面文案全部中文硬编码**（用户群为中文），不引入 i18n 框架；仅 ThemeToggle 等模板组件自带英文文案改为中文。组件内文案集中在组件文件顶部常量，便于后续如需 i18n 再抽取。
