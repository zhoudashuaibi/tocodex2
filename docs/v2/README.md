# toCodex2 v2 重写设计文档

本目录是 toCodex2 v2（模块化重写版）的完整设计文档，覆盖从实现原理、协议细节到前后端接口的完整规范，目标是**拿着文档即可独立复现整个系统**。

## 背景与目标

v1 的问题：

| 问题 | v1 现状 | v2 方案 |
|---|---|---|
| 后端臃肿 | `src/console-server.mjs` 单文件 5000 行（路由 + 调度 + 号池 + 监控全在一起） | Fastify 模块化，每业务域一个插件目录 |
| 前端臃肿 | `web/src/main.jsx` 单文件 2626 行，所有面板挤在一页 | shadcn-admin 布局：左侧菜单 + 右侧内容页 |
| 数据不稳 | 任务状态在内存 Map，重启丢日志；任务多了内存膨胀 | SQLite 全量落库，日志落盘 |
| 凭据易失 | 依赖 Windows DPAPI / macOS Keychain，Linux/Docker 下凭据重启即丢 | AES-256-GCM 加密入库（应用层密钥），全平台一致 |
| 登录烦 | 访问令牌只在内存，刷新页面就要重输密码 | HttpOnly Cookie + 服务端会话，30 天滑动过期 |
| 配置散 | codex2api Key 明文存浏览器 localStorage、明文存 monitor.json | 全部服务端化、加密存储、读取脱敏 |
| 代理简陋 | 单个代理输入框，随任务提交 | 独立代理列表模块：批量导入、一键测活、随机选路、无可用回退本机 |
| 驱动脆弱 | console 靠正则解析子进程 stdout 关键字驱动状态机 | 子进程输出结构化 NDJSON 事件流 |

核心原则：**ChatGPT 协议登录 / Codex OAuth / Sentinel 反检测 / TLS 指纹这套核心逻辑原样复用**，只重写控制台服务与前端。

## 已确认的技术决策

| 决策项 | 结论 | 备注 |
|---|---|---|
| 数据库 | SQLite（better-sqlite3） | 单文件、随 Docker volume 持久化；凭据 AES-256-GCM 加密入库 |
| codex2api 监控策略 | 分类处理 | 401 封禁 / 429 → 移入废弃号池；临时错误 → 自动重登修复（连败暂停保留待重授，不废弃）；可选自动补号（口径可选：按账号数量 / 按 codex2api 总并发+初始总余额，先传主池库存再从备用池补号） |
| 登录会话 | 30 天滑动过期 | HttpOnly Cookie + sessions 表，刷新页面不再要求重输密码 |
| 部署形态 | 单容器同源 | Node + Python(curl_cffi) + 前端构建产物同镜像，API 与页面同源，前置反代做 HTTPS |
| 后端框架 | Node.js 22 ESM + Fastify | 模块化路由 / JSON Schema 校验 / auth hook |
| 前端框架 | Vite + React 19 + TypeScript + Tailwind + shadcn/ui | 以 [shadcn-admin](https://github.com/satnaing/shadcn-admin) 为布局基座（TanStack Router + TanStack Query） |

## 术语表

| 术语 | 含义 |
|---|---|
| 备用号池（reserve） | 导入的 Outlook 邮箱账号池，尚未执行 ChatGPT 登录，导入时从邮件初始化余额与封禁状态 |
| 主号池（main） | 已完成 ChatGPT 邮箱验证码登录并持有 OAuth token 的账号池，是上传 codex2api 的来源 |
| 废弃号池（discard） | 从主号池移出的失效账号（codex2api 侧 401 封禁 / 429 限流 / 修复失败 / 手动废弃），保留原因与原始错误 |
| 加入主池 | 备用池账号执行 email_otp 登录流程，成功后移入主号池 |
| 授权 / 重新授权 | 对主号池账号执行（重新）登录并换取新的 OAuth token；优先用 refresh_token 刷新，失败回退完整登录 |
| 测活 | 通过代理用 curl_cffi 访问 chatgpt.com，判定 alive / cf_challenge / dead |
| 任务（job） | 一次登录 / 刷新 / 查余额 / 设置 2FA 的执行单元，以子进程方式运行 protocol-login |
| checkpoint | 登录断点（含 CookieJar），中断后可续跑，对冲 OAuth code 只能交换一次的限制 |
| codex2api | 下游账号池服务，通过其 admin API 上传/替换 OAuth 账号 |
